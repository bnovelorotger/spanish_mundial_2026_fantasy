# components/ui

shadcn/ui primitives. Generated by the shadcn CLI in Phase 1.

Rules:

- Only generated/installed primitives live here (button, card, input, dialog, etc.).
- Do not put domain components in this folder — those go in `../worldcup`.
- Do not edit files generated by shadcn unless you have a specific reason.
- shadcn primitives must be restyled with the Tailwind tokens from
  [docs/BRANDBOOK.md](../../docs/BRANDBOOK.md) §18 — no leftover shadcn
  default colors in shipped UI.
